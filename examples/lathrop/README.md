# Lathrop Problem

## Description
This benchmark was originally documented by K. D. Lathrop in the papers "Ray Effects in Discrete Ordinates Equations" (1968) and "Remedies for Ray Effects" (1971) to show and address the ray effect phenomena that appear in discrete ordinates calculations.
It models a flat, square source surrounded by a non-multiplying medium.
A scattering ratio ($\Sigma_s/\Sigma_t$) was specified as 2/3, with a total macroscopic cross section of 3/4 1/cm.
From here, a macroscopic scattering cross section was determined to be 1/2.
